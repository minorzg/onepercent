# 🚀 1% (One Percent) — SaaS De Développement Personnel & Habitudes

**1% (One Percent)** est une plateforme SaaS ultra-rapide et responsive conçue pour aider les utilisateurs à construire de meilleures habitudes au quotidien grâce à l'amélioration continue de 1% par jour.

📍 **Démo en ligne :** [https://onepercent.xo.je](https://onepercent.xo.je)

---

## ✨ Fonctionnalités Principales

* 📊 **Tableau de Bord interactif** : Suivi quotidien des objectifs, calcul automatique du *Streak* (série de jours consécutifs) et barre de progression dynamique.
* 📅 **Planning & Calendrier** : Planification récurrente des activités par jour de la semaine et gestion des niveaux de difficulté.
* 📈 **Analytics & Statistiques** : Visualisation des performances et historiques d'accomplissement.
* 💳 **Paiement Crypto automatisé (OxaPay)** : Système de mise à niveau vers les plans **Pro** et **VIP** via paiement automatique en crypto-monnaies.
* 🌗 **Mode Sombre / Clair** : Interface utilisateur adaptative avec stockage des préférences locales (*localStorage*).
* 📱 **Design Mobile-First** : Navigation fluide sur smartphone avec barre de navigation dédiée (*Bottom Nav*), menu latéral slide-over et gestion des gestes tactiles.
* ✉️ **Système d'E-mails (Resend API)** : Envoi d'e-mails transactionnels pour la confirmation d'inscription et la gestion de compte.

---

## 🛠️ Stack Technique

* **Frontend** : HTML5, CSS3 (Variables CSS, Flexbox, Grid responsive), JavaScript (ES6+ Vanille)
* **Backend** : PHP 8.x (Architecture modulaire, sessions sécurisées)
* **Base de données** : MySQL / MariaDB (Via PDO pour prévenir les injections SQL)
* **Paiement** : API OxaPay (Merchant Integration)
* **Gestion des mails** : API Resend (via cURL PHP)
* **Hébergement** : InfinityFree (Apache / Webmail / SSL)
